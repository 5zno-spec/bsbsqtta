# يوم النمر

لعبة أنشطة يومية: زراعة، أكل، استحمام، تنظيف، نوم. موقع ثابت لا يحتاج بناءً.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا على GitHub وارفع إليه محتويات هذا المجلد.
2. من المستودع: Settings > Pages.
3. في Source اختر Deploy from a branch، ثم الفرع main والمجلد / (root)، واضغط Save.
4. بعد دقيقة تقريبًا يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## من الطرفية
```
git init
git add .
git commit -m "يوم النمر"
git branch -M main
git remote add origin https://github.com/اسم-المستخدم/اسم-المستودع.git
git push -u origin main
```

## الزراعة
1. اضغط على البذرة 🌰 فتقع على الأرض.
2. تظهر فقاعات فيها صابونة 🧼 أو رشاش 🚿. اضغط على الرشاش لتسقي البذرة فتصير نبتة.
3. بعد أن تنمو تصير جزرة. المسها لتحصدها ثم أطعم بها النمر.

## التعديل
- الشخصية: استبدل `tiger.png` بأي صورة بخلفية شفافة.
- سرعة النمو: `GROW_MS` في `game.js`.
- سرعة نقص الجوع والنظافة والطاقة: دالة `tick` في `game.js`.

## ملاحظة عن الصور
مجلد `parts` فيه أجزاء النمر المقصوصة (الجسم والذيل واليد والرجلان) وهي التي تتحرك. الملف `tiger.png` هو الأصل.
